# Noda v2 · Macropad direction

Отдельный прототип новой веб-версии Noda. Текущий сайт в `design/` не изменяется.

Реализовано:

- вход по паролю `2244` с сессионной блокировкой интерфейса;
- вертикальная аппаратная навигация и статичные декоративные ручки;
- проекты с двумя широкими 16:9-скриншотами, а у bembox — с тремя мобильными;
- безопасное копирование адреса сервера, описания БД и пути проекта без паролей и токенов;
- поиск и фильтры проектов;
- файлы с выбором и drag-and-drop;
- наглядный маршрут передачи, прогресс и пауза;
- интерфейсы удалённого ПК, помощника и заметок;
- локальное хранение заметок;
- увеличенные оригинальные и сгенерированные логотипы проектов.

Пароль в статическом прототипе является интерфейсным шлюзом, а не полноценной серверной защитой. Перед публикацией авторизацию и выдачу инфраструктурных данных необходимо перенести в защищённый backend.

Локальный просмотр:

```powershell
python -m http.server 4186 --directory noda-v2
```
