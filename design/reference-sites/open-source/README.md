# Open-source references

These files are visual references used for the rteam.ru project map redesign.

- `openflowkit-canvas.png` — [Vrun-design/openflowkit](https://github.com/Vrun-design/openflowkit), commit `52e5178`, MIT. Reference for the infinite-canvas interaction, dotted field, nodes and zoom controls.
- `openclaw-glass-panel.png` and `openclaw-glass-timeline.png` — [karem505/openclaw-agent-dashboard](https://github.com/karem505/openclaw-agent-dashboard), commit `f22f444`, MIT. Reference for translucent panels, borders and compact dark controls.

The site keeps its own project data, brand assets, layout and implementation. The reference screenshots are not published as part of the public interface.
