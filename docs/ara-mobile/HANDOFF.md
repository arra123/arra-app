# HANDOFF: мобильная «Ара» вместо «Ноды»

Ветка `ara-mobile`. Всё написано и проверено в облачной сессии без секретов:
сборку, выкладку сервера и установку ara-link делает агент на ноутбуке по
инструкции ниже.

## Что сделано

1. **Старая «Нода» убрана целиком**: финансы, долги, компенсации, заметки,
   перенос файлов, удалённый экран/терминал, УльянаOS, виджет, десктопные
   клиенты `pc-app` и `pc-agent`, их серверные маршруты и зависимости.
   Оставлены вход (auth), push, ключи устройств и диктовка (`/ai/transcribe`).
2. **Сервер** (`server/src/ara/`, `server/src/routes/{ara,devices,relay}.js`):
   протокол `ara.*` поверх каналов `/agent` (компьютер) и `/client` (телефон).
   Снимки компьютеров в памяти, склейка ноутбука и ПК, подписки на переписку,
   маршрутизация команд с ответами по `reqId` и таймаутами, файлы
   компьютер ↔ телефон (с Range для видео), push при `working → waiting / error`.
   Описание — `docs/ara-mobile/PROTOCOL.md`.
3. **ara-link** (`ara-link/`): Python 3 + `websockets`, вызывает существующие
   скрипты «Ары»; systemd user unit, `install.sh`, README, тест.
4. **Приложение** (`src/`): Expo SDK 56, тёмная тема, Liquid Glass, Reanimated 4,
   хаптика, push; название «Ара», версия 2.0.0. Bundle ID, slug, EAS-проект и
   домен API не менялись.

Исправлено по ревью: push не глушится экраном агента на заблокированном
телефоне (телефон отписывается в фоне, сервер учитывает только «живые»
подписки); сервер пингует WebSocket и снимает «пропавший» ноутбук; закрытие
сокета во время запроса в БД больше не оставляет «призрачный» компьютер;
`ara.file` отдаёт только точные пути медиа из переписки агента или ответа
Ары (не из текста с телефона, с проверкой `realpath`), кеш файлов — в
пределах той же переписки; загрузка большого видео не обрывается таймером;
удаление и перевыпуск ключа сразу отключают компьютер; ключи и JWT не
пишутся в журнал сервера; таймауты сервера длиннее, чем у ara-link (без
двойного запуска агента); «отправляю…» пропадает по счёту сообщений; в чате
с Арой вопросы не накладываются; переписка больше 6 МБ обрезается.

На iPhone ничего не запускалось: нет Mac и секретов. Liquid Glass, SF Symbols,
хаптика, клавиатура, push и видео на устройстве — в чек-листе ниже.

`CLAUDE.md` и `AGENTS.md` в `.gitignore`, поэтому в облачный клон они не
попали. Делал по `TASK.md`: версионная документация Expo v56 (сверял API
по типам установленных модулей), без нативных SwiftUI-контролов (меню и
переключатели — свои, на `expo-glass-effect`), цвета только из
`src/constants/theme.ts`, весь текст по-русски. **Сверь с этими файлами
перед сборкой.**

## Миграции БД

Одна новая: `server/migrations/021_ara.sql` — таблица `apple.ara_agent_states`
(последнее состояние каждого агента, чтобы push не терялся после рестарта).
Идемпотентная (`CREATE TABLE IF NOT EXISTS`). `npm run migrate` применяет все
файлы по порядку; старые тоже идемпотентны.

Старые таблицы (`transactions`, `debts`, `notes`, `reimbursements`, `cry_logs`,
`chat_messages`…) код больше не использует, но они **не удалены**. Если нужно
почистить (данные не переносятся):

```sql
SET search_path TO apple;
DROP TABLE IF EXISTS transaction_items, transactions, debts, reimbursements, notes,
  chat_messages, chat_threads, assistant_threads, cry_logs, pingpong_matches, files CASCADE;
```

## Выкладка сервера

`scripts/deploy_server.mjs` в репозитории нет (он у тебя локально). Новых npm-зависимостей
у сервера нет, `.env` прежний.

```sh
node scripts/deploy_server.mjs          # как обычно
# на сервере, в каталоге server/:
npm run migrate                          # применит 021_ara.sql
# перезапуск сервиса — как обычно
curl https://aura.5.42.122.102.sslip.io/health   # {"ok":true,"service":"ara",…}
```

Если перед Node стоит обратный прокси (nginx/Caddy):
- WebSocket для `/agent` и `/client` должен проходить, как и раньше;
- `client_max_body_size` не меньше 512m для `POST /ara/upload` и `POST /ara/blob`
  (видео с компьютера);
- заголовок `Range` для `GET /ara/blob/:id` должен доходить до Node (без него
  AVPlayer не играет mp4).

Файлы «Ары» лежат в `UPLOAD_DIR/ara` (по умолчанию `server/uploads/ara`) сутки и
чистятся при старте.

## Сборка iOS

Нативные зависимости изменились (добавлены `expo-notifications`, `expo-video`,
`react-native-keyboard-controller`; убраны `expo-camera`, `expo-media-library`,
`expo-document-picker`, `expo-screen-orientation`, `expo-widgets`,
`@expo/ui`, `react-native-webview`, `@react-native-community/datetimepicker`),
поэтому нужна **новая сборка**, OTA не хватит. Версия поднята до 2.0.0, при
`runtimeVersion: appVersion` OTA-обновления старым сборкам 1.x не уйдут.

**Push, до сборки:**
1. `expo-notifications` добавляет entitlement `aps-environment`. В
   `eas.json` у production `credentialsSource: "local"`, поэтому профиль
   `credentials/profile.mobileprovision` должен включать Push Notifications:
   включи capability у App ID `com.arratima.aura` в Apple Developer,
   перевыпусти App Store профиль и положи в `credentials/` (и в секрет
   `IOS_PROFILE_B64`, если собираешь через GitHub Actions). Иначе подпись
   упадёт с ошибкой про `aps-environment`.
2. Для доставки через Expo Push нужен APNs-ключ в EAS:
   `eas credentials -p ios` → production → Push Notifications → добавить ключ
   (.p8 с включённым APNs). Это не зависит от `credentialsSource: local`.

```sh
npm ci
npx tsc --noEmit && npm run lint
eas build -p ios -e production
eas submit -p ios -e production
node scripts/asc-add-latest-to-group.mjs   # положить сборку в группу TestFlight
```

Внимание: `.github/workflows/ios.yml` собирает и отправляет в TestFlight при
каждом push в `master`, так что слияние PR запустит сборку, если секреты заданы.

## Установка ara-link на ноутбуке

1. `sudo pacman -S --needed python-websockets`
2. В приложении: **Настройки → Компьютеры → Ноутбук → Подключить** (или
   «Ключ», если уже подключён) — покажет команду и конфиг, копируются нажатием.
3. На ноутбуке, в клоне репозитория:
   ```sh
   cd ara-link && ./install.sh <ключ> laptop
   journalctl --user -u ara-link -f       # «на связи с … как laptop»
   python3 ~/.local/share/ara-link/ara_link.py --check   # снимок агентов
   ```
4. Картинки и видео агентов **ПК**, а также фото с телефона агентам ПК идут по
   ssh: впиши в `~/.config/ara-link/config.json` `"pcSsh": "<хост ПК>"` — тот
   же, что использует `ara-pc` (посмотри в `~/.config/quickshell/ara/scripts/ara-pc`),
   и `systemctl --user restart ara-link`. Без этого всё остальное с ПК работает.
5. Новые агенты на ноутбуке открываются в kitty из systemd-юнита. ara-link сам
   находит `WAYLAND_DISPLAY` и `HYPRLAND_INSTANCE_SIGNATURE`, но надёжнее
   передать окружение сессии: `exec-once = dbus-update-activation-environment --systemd --all`
   в конфиге Hyprland.
6. Отладка: `ARA_LINK_DEBUG=1 python3 ~/.local/share/ara-link/ara_link.py`.

Что стоит сверить со скриптами на ноутбуке (в облаке их нет, делал по таблице
из TASK.md):
- `ara-transcript` вызываю без `mtime`: ara-link сам делает `stat` журнала и
  зовёт скрипт, только если файл изменился; для ПК — `ara-pc transcript` раз в 3 с.
- `ara.model` отправляет в терминал текст `/model opus|sonnet|haiku` (только
  для Claude; у Codex выбор модели в приложении не показывается).
- Codex на ноутбуке запускается как
  `exec codex --dangerously-bypass-approvals-and-sandbox [--model m] $ISLAND_TASK`
  (Claude — строго по TASK.md). Команды можно поменять в конфиге (`launch`).
- Действия Ары (`{"t":"action",…}`) показываются чипом с полем `text`
  (или `title` / `summary` / `kind`).

## Экраны (словами)

- **Вход**: тёмный фон, значок Ары, «Вход / Регистрация», логин, пароль, белая кнопка-капсула.
- **Главный**: сверху стеклянная кнопка настроек, переключатель «Работа / Разговор»
  (белая капсула переезжает пружинкой) и стеклянная кнопка «✎» с меню
  «Новый Claude / Новый Codex / Новый чат с Арой».
  - «Работа»: поиск, секции «НОУТБУК» и «ПК» (справа «2 агента» или «не в сети»);
    карточка агента — значок Claude (оранжевая звёздочка) или Codex (`</>`),
    проект, строка «работает · 4 мин · задача» с цветным статусом, справа
    точка статуса (у работающего пульсирует) и чип «стол 4». Ниже «НЕДАВНИЕ
    СЕССИИ» (12, потом «Показать ещё»). Тянуть вниз — обновить. Нет компьютеров
    — карточка «Компьютеры не на связи» с кнопкой «Подключить компьютер». Нет
    связи с сервером — жёлтая плашка.
  - «Разговор»: «Новый чат» и список чатов с Арой (долгое нажатие — удалить).
- **Агент**: стеклянная шапка — «‹», значок, проект, «Ноутбук · стол 4 ·
  ~/Claude/helper», справа капсула модели «⚡ Opus 5.5 ⌄» (меню: Opus / Sonnet /
  Haiku, «Остановить (Esc)», «Скопировать путь», «Новый агент в этой папке»).
  Под ней строка «● Работает 4 мин · сейчас: Читает AraWindow.qml» или
  «Закончил 3 мин назад · ждёт ответа», карточка «План ▬▬▬ 5 из 7» с «сейчас: …»,
  раскрывается в чек-лист. Лента открывается на последнем сообщении: пузыри
  пользователя справа, ответы агента Markdown-ом (таблицы с горизонтальной
  прокруткой, списки, код с кнопкой копирования), действия — капсула
  «18 действий · Правит ara_link.py ⌄», раскрывается списком с иконками.
  Картинки — миниатюры, по нажатию на весь экран (щипок, двойной тап, свайп
  вниз закрывает). Видео — плеер прямо в ленте (полный экран, PiP). Внизу
  стеклянное поле: «+» (галерея / камера), микрофон (диктовка через Whisper
  на сервере; клавиатурная диктовка iOS тоже работает), отправка; пока агент
  работает и поле пустое — белая кнопка «■ Остановить». Отправленное висит
  «отправляю…», пока не появится в переписке. Закрытая сессия — плашка
  «Сессия завершена» с кнопкой «Новый агент».
- **Чат с Арой**: шапка с названием чата и «Чётко / Поговорить»; ответ печатается
  потоком, пути к картинкам/видео в тексте показываются как медиа; действия
  Ары — чипы; ошибка — «Повторить». В поле ввода справа «⚡ Sonnet ⇅» (Haiku /
  Sonnet / Opus). Пустой чат — подсказки. Чаты хранятся на телефоне.
- **Новый агент** (лист снизу): Claude / Codex, «Ноутбук / ПК» (офлайн — недоступно),
  чипы папок из текущих и недавних сессий этого устройства + «Другая папка…»,
  модель, первая задача, «Запустить» → «Открываю терминал…» → когда агент
  появится в снимке, сразу открывается его экран.
- **Настройки** (модально): компьютеры (на связи / через ноутбук / не в сети;
  «Подключить», «Ключ», перевыпуск, удаление) с карточкой команды установки и
  конфига; уведомления; аккаунт и «Выйти»; версия.
