# Раунд 114: ответы на вопросы агента с телефона

После правок `ROUND_113.md` доделай интерактивные вопросы в диалоге агента.
Пользователь хочет отвечать с iPhone на все вопросы и выборы Claude/Codex,
которые появляются в терминале. Сейчас `QuestionCard` показывает только первый
вопрос Claude `AskUserQuestion`, всегда нажимает цифру в терминале и не дает
нормально ответить своим текстом. Codex раньше вовсе не передавал вопросы.

Парсер `notch-island/ara/scripts/ara-transcript` на ноутбуке и ПК уже расширен:
в `ara.transcript.data.question` у Codex теперь есть:

```json
{
  "id": "call_id",
  "answerVia": "message",
  "questions": [{
    "question": "...",
    "header": "...",
    "multi": false,
    "options": [{"label": "...", "description": "..."}]
  }]
}
```

`answerVia: "message"` означает: выбранный ответ или свой текст отправляй как
обычное сообщение через `ara.send` в тот же агент. Для прежнего Claude
`AskUserQuestion`, где `answerVia` отсутствует, варианты выбираются через
`ara.key` в терминале. Не полагайся только на это: после реального ответа
проверь, что карточка исчезает и агент продолжает разговор.

Сделай в карточке:

- Все вопросы по порядку, а не только первый. Для каждого покажи заголовок,
  текст и варианты. Поддержи `multi` у Claude и подтверждение выбранных
  вариантов; отправляй клавиши в том виде, который реально ожидает CLI.
- Видимый пункт «Свой ответ» и ввод текста, даже если вариантов нет.
  Согласуй его с действующим полем чата: нельзя создавать тупик без отправки.
- После нажатия покажи отправку и результат. Не теряй вопрос при сетевой ошибке,
  не отправляй ответ дважды. Вопрос не должен перекрывать ленту целиком.
- Сохрани доступность: нормальные зоны касания, VoiceOver названия вариантов,
  состояние выбора и фокус ввода.
- Проверь отдельно Claude и Codex на синтетическом `Transcript` с несколькими
  вопросами, вариантами и свободным ответом, а также отправку через
  соответствующий `ara.key` или `ara.send`.

Работай через облачный Claude Code на `ara-mobile`, проверь `npx tsc --noEmit`,
`npm run lint`, `npx expo export --platform ios`, затем коммить и пушь.
Сборку и TestFlight выполнит агент на ноутбуке.
