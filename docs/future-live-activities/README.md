# Отложенная работа: Live Activities

Эти файлы - заготовки, а не готовая функция. Они не подключены к приложению или серверу, миграция не применялась, профиль расширения не создавался. В сборке 119 Live Activities отсутствуют.

После получения доступа из ../apple-access.md нужно проверить API expo-widgets для используемой версии, настроить App Groups и подпись расширения, подключить регистрацию APNs-токена активности и обновления на сервере. Затем проверить на настоящем iPhone запуск, фон, блокировку, завершение и повторное подключение. Не публиковать .p8 или секреты в Git.

Обновления Arra выпускаются через новые сборки TestFlight; OTA отключено по просьбе пользователя.
