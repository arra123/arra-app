Пункт закрывается после проверки результата, не после одной правки кода.

- [ ] Уведомление о реальном завершении Codex и Claude; аккуратный показ, без сообщений о промежуточной работе.
- [ ] Точные модель и reasoning в шапке; выбор High во время работы с подтверждением применения.
- [ ] Видимый статус сжатия контекста до его завершения.
- [ ] Плавное перемещение диалогов, без скачков.
- [ ] Компактный верхний блок и подходящее размещение настроек и Stop.
- [ ] Заголовок недавних сессий доступен при прокрутке.
- [ ] tito: аккуратная сцена чтения сообщения, без выступающих деталей.
- [ ] Git: соединённые узлы, без плавающих точек.
- [ ] Тени пропорциональны каждому персонажу и его положению.
- [ ] Номера диалогов в цвет маскота проекта.
- [ ] Глаза не смещаются при моргании; собственные конечности, без дополнительных палок.
- [ ] Помощники наследуют персонажа проекта; графика не обрезается.
- [ ] Иконка helper сохраняет пропорции и читаемый размер.
- [ ] Верхний остров использует проектных маскотов.

## iPhone

- [ ] Уведомление открывает нужного рабочего агента, а не обычный разговор.
- [ ] Live Activity только для результата/вопроса, без постоянного счётчика работающих агентов.
- [ ] Привязанные к проекту маскоты в блоке и диалоге.
- [ ] Боковые функции проектов и выбор персонажа доступны на телефоне.
- [ ] Данные быстро обновляются после возвращения; отвеченные вопросы исчезают.
- [ ] Обновление между ПК, ноутбуком и телефоном не показывает старые данные.
- [ ] Плавная прокрутка длинных сообщений и работа клавиатуры.
- [ ] Полная проверка шапки и границ сцен.
- [ ] Сборка доставлена через TestFlight; проверены обработка Apple и группа тестировщиков.
- [ ] Проверено на iPhone: прокрутка, уведомление, выбор High, отправка видео, маскоты.

## Проверено в коде и тестах

- Каталог моделей берётся через текущий Codex app-server, а не общий устаревший кэш. GPT-6.1-Sol реально поддерживает High.
- High для текущего занятого диалога принят в очередь; фактическое применение проверяется после завершения ответа.
- Исправлена привязка правого плана к UUID диалога.
- Проверены обработчик уведомлений и распознавание реального reasoning/compaction; окончание настоящего агента ещё требует отдельной проверки.
- Сборка iPhone 2.0.1: https://github.com/arra123/arra-app/actions/runs/37115417643 — доставка не считается завершённой до VALID и группы TestFlight.
- Прямая проверка App Store Connect заблокирована ответом 403 `FORBIDDEN.REQUIRED_AGREEMENTS_MISSING_OR_EXPIRED`. Владелец аккаунта должен принять/продлить требуемое Apple соглашение; автоматически соглашение не принимается.
- Повторная проверка без персональных данных тестировщиков: `node scripts/check-release.mjs 2.0.1`.
- Ноутбук повторно не найден в локальной сети; переноса данных пока не было.
